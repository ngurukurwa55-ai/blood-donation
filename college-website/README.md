# SACOHAS College of Health and Allied Sciences

A professional, modern, and responsive website for SACOHAS College of Health and Allied Sciences in Tanzania.

## Overview

This website was built following the approved project specification for SACOHAS College. It features a clean, professional design with a focus on usability, accessibility, and responsive design.

## Features

- ✅ Fully responsive (mobile-first design)
- ✅ Professional color system (Navy + Gold + White)
- ✅ Accessible (WCAG AA compliant)
- ✅ Keyboard navigable
- ✅ Mobile hamburger menu
- ✅ Program search and filtering
- ✅ Program details modal
- ✅ FAQ accordion
- ✅ Image gallery with lightbox
- ✅ Contact form with validation
- ✅ Back-to-top button
- ✅ Semantic HTML5

## Technology Stack

- HTML5
- CSS3 (Custom, no frameworks)
- Vanilla JavaScript (No libraries)

## Pages

1. **Home** - Hero section, quick access, programs preview, news
2. **About** - Mission, vision, values, institutional information
3. **Academic Programs** - Program cards with search and filtering
4. **Admissions** - Step-by-step process, requirements, FAQ
5. **Student Life** - Activities, organizations, support services
6. **News & Events** - News articles with category filtering
7. **Campus & Gallery** - Campus information with image lightbox
8. **Contact** - Contact information with form validation
